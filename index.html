Version-aware page sign-off

Know exactly which page version was approved.

Signlight adds a simple traffic-light sign-off to any Confluence page. Green means approved. Yellow means the page changed. Red means there is no active sign-off.

The traffic-light workflow

One glance tells the whole story.

The status is derived from the active sign-off and the live Confluence page version, so it never depends on a separate checklist staying in sync.

Small by design

Enough accountability. Almost no process.

Signlight is for lightweight internal acknowledgements and approvals. It is not a regulated or legally binding e-signature product.

Atlassian identity

People sign with the account already logged into Confluence.

Version aware

Any published page change automatically turns green to yellow.

Revocable

Only the active signer can revoke, and the event is retained.

No content copy

Signlight stores identifiers, versions and audit timestamps—not the page body.

Hosted on Forge

Your approval flow stays inside Atlassian.

The app runs on Atlassian Forge and uses Forge app storage. There is no separate Signlight account, password or external dashboard.
