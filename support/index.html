Signlight for Confluence

Support

Need help installing Signlight or understanding a page status? Send a concise description and, if useful, a screenshot to Reware Apps support.

Quick start

  1. Ask a Confluence administrator to install Signlight.
  2. Edit a Confluence page and type /Signlight.
  3. Select Signlight page sign-off and publish the page.
  4. Open the published page and select Sign page.

What the colors mean

  • Red: no active sign-off exists.
  • Green: the active sign-off matches the current page version.
  • Yellow: the page was updated after signing.

Common questions

Why can't I sign while editing?

A draft does not yet have the published version readers will see. Publish the page, then sign it from view mode.

Who can revoke a signature?

Only the Atlassian account that created the active signature.

Does a page edit delete the signature?

No. The status becomes yellow and retains the signer and signed page version until the current version is signed or the signature is revoked.

Is this a legal electronic signature?

No. Signlight is a lightweight internal page acknowledgement tool. It is not designed for regulated or legally binding e-signatures.
